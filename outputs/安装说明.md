# 雨课堂课件批量下载

## Safari（macOS）

1. 在 **Safari → 设置 → 扩展**启用 Userscripts。在雨课堂标签页点击工具栏里的 **Userscripts** 图标，按提示允许它访问雨课堂网站。
2. 点击 Userscripts 弹窗里的文件夹图标，打开脚本目录。将 `ykt-downloader.user.js` 放进该目录。
3. 回到雨课堂，再次打开 Userscripts 弹窗，等它加载完成后关闭。刷新课程页面，点击右下角的 **下载课件**。

已安装旧版时，用新版 `ykt-downloader.user.js` 替换原脚本，再刷新雨课堂。

## Chrome 或 Edge（Windows、macOS）

1. 解压 `ykt-downloader-chrome-edge.zip`。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用**开发者模式**。
3. 点击**加载已解压的扩展程序**（Edge 中为**加载解压缩的扩展**），选择包含 `manifest.json` 的 `ykt-downloader` 文件夹。
4. 登录雨课堂并打开新版课程页面。刷新已经打开的标签页，在右下角点击 **下载课件**。

已安装旧版时，将新版文件解压到原扩展目录，在扩展管理页点击**重新加载**，再刷新雨课堂。

## 下载地址

- **浏览器默认位置**会在导出后自动发起下载，位置由浏览器设置决定。常见位置为 Mac 的「下载」`~/Downloads` 和 Windows 的「下载」`%USERPROFILE%\Downloads`。可以在浏览器的下载列表里点击「在访达中显示」或「在文件夹中显示」。
- **每次选择位置**会先生成 PDF 或 ZIP。Chrome 和 Edge 中点击**选择保存位置**，在系统窗口里选文件夹和文件名。Safari 中右键点击**保存文件**，选择**下载链接文件为…**。如果 Chrome 或 Edge 的选位置按钮不可用，也可以右键选择**将链接另存为…**。
- 如果希望自动保存到同一个自定义文件夹，在 Safari 的「设置 → 通用 → 文件下载位置」或 Chrome／Edge 的「设置 → 下载」里设定文件夹，再在扩展中选**浏览器默认位置**。

## 导出

- 在「课程」下拉框切换课程。可搜索、逐项勾选，也可勾选章节名称选中整组课件。
- **下载所选**导出勾选项。**下载全部**导出该课程列表中的全部课件，不受搜索条件影响。
- 每个课件单独生成一份 PDF，文件名包含课件标题。导出一项时直接保存 PDF。批量导出时，PDF 按课件顺序编号并打包为 ZIP，即使只有一项成功也会生成 ZIP。
- 可选 A4 横向或竖向，每页排 1、2 或 4 张。默认为 A4 横向，每页 1 张。
- 导出在浏览器内完成。原版 PDF 可用时保留其页面内容。若站点只提供幻灯片图片，则保留站点提供的分辨率，JPEG 保留原编码。
- 部分页面失败时，已导出的文件仍可保存，面板中可查看失败条目。浏览器未自动保存时，点击面板里的**再次保存文件**。

适用于当前已登录账号可访问的 `yuketang.cn` 新版课程页面。如课程目录或课件列表读取失败，先确认该内容能在雨课堂正常打开，再在面板中刷新。
